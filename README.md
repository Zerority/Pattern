# LeetCode Patterns

Ce projet vise à compiler les principaux **modèles algorithmiques** que j'ai appris et mis en pratique sur LeetCode.

Contrairement à un simple recueil de solutions, cette archive met l'accent sur la **compréhension des techniques** plutôt que sur la résolution d'un problème spécifique. Chaque dossier présente un modèle réutilisable, son principe, son implémentation, sa complexité, les erreurs courantes et des exercices pour l'appliquer.

---

## Contenu

Chaque pattern contient généralement :

- une explication du principe ;
- les situations où il est pertinent de l'utiliser ;
- un template Python réutilisable ;
- une analyse de complexité ;
- une sélection de problèmes LeetCode.

---

## Patterns étudiés

- Prefix Sum
- Two Pointers
- Hash Map / Hash Set
- Sliding Window
- Stack
- Binary Search
- Linked List

## Objectifs

- Développer une compréhension solide des principaux patterns algorithmiques.
- Constituer une documentation personnelle claire et structurée.
- Disposer d'une ressource de révision avant les entretiens techniques.
- Suivre ma progression au fil de mon apprentissage.

---

> *"Comprendre un pattern est souvent plus utile que mémoriser des dizaines de solutions."*
